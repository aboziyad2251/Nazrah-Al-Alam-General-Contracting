5 · What Exceeded the Plan

Six items were delivered beyond the original remediation plan scope.

⭐
Second hook violation fixed — EquipmentCarousel.tsx: useTranslations('common') was called inline inside the JSX return block. Hoisted to const tc at component top. Prevented potential inconsistent renders in production. Not in original plan.
⭐
type="button" on equipment tab buttons — Prevents accidental form submission; satisfies jsx-a11y static linter. Best practice beyond scope.
⭐
Unused tc variable removed from Navbar.tsx — Eliminates no-unused-vars ESLint warning introduced during the accessibility pass.
⭐
Unused Image import removed from EquipmentCarousel.tsx — Cleans import surface after refactor.
⭐
Skip link fully bilingual via getTranslations — Plan listed this as optional; implemented with EN "Skip to content" and AR "انتقل إلى المحتوى" in messages/en.json and messages/ar.json.
⭐
Anti-Patterns score reached 4/4 — Plan only targeted 3/4 for this dimension. The stagger cap + blob GPU promotion together pushed it to a perfect 4 — directly responsible for the +1 bonus point above target.
6 · Residuals Deferred to Pass 2

Five pre-existing findings were identified during the final verification scan but deferred — none were introduced by this pass.

⚠️
Contact page emoji icons — contact/page.tsx: Phone, email, location emojis not yet replaced with inline SVG (PhoneIcon, MailIcon, PinIcon from Phase 6 Step A). Priority: P2.
⚠️
Hardcoded WhatsApp colors — contact/page.tsx:81: CTA link uses bg-[#25D366] and hover:bg-[#1ebe5d] (incorrect hover value) instead of bg-whatsapp hover:bg-whatsapp-hover. Priority: P2.
⚠️
SVG stroke hex values — SectionHeader.tsx:46 and equipment/[category]/page.tsx:84: stroke="#E8B339" in inline SVG path elements. SVG presentation attributes cannot reference CSS custom properties without a currentColor refactor. Priority: P2 (low).
⚠️
Legacy HomeHero inline style — HomeHero.tsx:31: #E8B339 in backgroundImage style prop. This component is only used by the non-locale root / page, not the main [locale] route. Priority: P2 (low).
⚠️
Form input focus pattern — QuoteForm.tsx:45: Inputs use focus:border-gold focus:outline-none. Consider migrating to focus-visible:border-gold focus-visible:ring pattern. Priority: P1 (low).
